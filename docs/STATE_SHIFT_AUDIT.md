1. **Monolithic Static Pages**: Navigation requires full-page reloads, breaking any continuous visual narrative or state transition.
2. **Missing Dynamic Research Topology**: The conceptual connection between reasoning reliability, agent safety, RL plasticity, and distributed consensus is currently presented as disconnected lists.

5. **Mobile Viewport Deficiencies**: Complex data tables and paper abstracts cause horizontal constraint issues on smaller mobile screens (<390px).
6. **Generic Profile GitHub README**: The root `README.md` only documents a single sub-project rather than establishing the overarching **STATE / SHIFT** research identity.
