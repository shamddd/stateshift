# Security Policy

## Supported Versions
| Version | Supported |
| :--- | :--- |
| `1.0.0-rc1` / `main` | :white_check_mark: |
| Historical drafts | :x: |

## Reporting a Vulnerability
If you discover a security vulnerability, credential leak, or sensitive data exposure in this repository, please do NOT file a public issue.

Instead, please send an encrypted or private report to:
- Principal Investigator: Sham Satish Thakare (`shamthakare3000@gmail.com`)
- Subject line: `[SECURITY] StateShift Vulnerability Report`

We will review reports within 48 hours and coordinate remediation before public disclosure.
