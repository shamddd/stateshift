# Security Policy

## Supported Versions

Project StateShift is an academic research repository. We provide active maintenance and security patches for the primary release branch:

| Version / Branch | Supported |
| :--- | :---: |
| `release/stateshift-publication-2026` | Yes |
| `main` | Yes |

---

## Reporting a Vulnerability

If you discover a security vulnerability, unintended credential exposure, or sensitive data leak in this repository:

1. **Do not open a public issue.**
2. Send an encrypted or direct email to the Principal Investigator at `shamthakare3000@gmail.com` with the subject line `[SECURITY] StateShift Vulnerability Report`.
3. Include detailed steps to reproduce the issue, affected commits or files, and potential impact.

We take security, computational integrity, and credential privacy seriously and will respond promptly to investigate and remediate reported issues.
