## 2. Mandatory NeurIPS Submission Policies

1. **Double-Blind Review**:
   - The submission PDF and supplemental code must be fully anonymized.
   - Author names, affiliations, GitHub profile links (`github.com/shamddd`), institutional emails, and acknowledgments must be omitted.
   - Prior arXiv/preprint citations must be cited in the third person without self-identifying language.
2. **Dual-Submission Policy**:
   - Submissions must not be concurrently under review at any other peer-reviewed journal or conference.
   - The prior Elsevier *Artificial Intelligence* submission (ARTINT-D-26-01491) was officially closed/rejected in August 2026. Because no active review process is ongoing, dual submission is strictly satisfied.
3. **Generative AI Policy**:
   - Generative AI tools (e.g. LLMs) used for drafting, code assistance, or text polishing must be disclosed in the NeurIPS Paper Checklist.
   - AI tools cannot be listed as authors.
4. **Reproducibility & Checklist**:
   - NeurIPS mandates the completion of the official Paper Checklist covering data access, compute details, error bars, and code availability.
