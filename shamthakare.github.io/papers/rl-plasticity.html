Predicting Reinforcement-Learning Plasticity of Intermediate Language-Model Checkpoints: A Cross-Architecture Diagnostic Study

Sham Satish Thakare

Abstract

Formulates diagnostic probing vectors φ(C_k) measuring layer-wise representation entropy and singular value spectrum decay rates. Demonstrates that checkpoint plasticity predicts downstream GRPO reward gain β_RL with R² = 0.91 (p = 0.0004), consuming < 2% of the compute required for full RL policy gradient rollouts.
