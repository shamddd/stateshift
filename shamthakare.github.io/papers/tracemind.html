TraceMind: Graph-Constrained Causal Reasoning for Root-Cause Localization in Microservice Systems

Sham Satish Thakare

Abstract

Topological causal walks over OpenTelemetry Service Dependency Graphs. Achieves 100.0% Top-1 root cause localization accuracy (MRR = 1.00) across 24 fault scenarios in CausalOpsBench, outperforming unconstrained LLM reasoning (Top-1 = 0.0%, MRR = 0.44).
